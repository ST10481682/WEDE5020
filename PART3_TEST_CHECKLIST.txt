## IMPORTANT FORM SUBMISSION NOTE

The website is hosted on GitHub Pages. GitHub Pages does not provide built-in form processing.

The current JavaScript uses mailto to open the visitor's email application. Visitors must send the prepared email themselves.

Automatic form storage and submission would require an external form-processing service.
